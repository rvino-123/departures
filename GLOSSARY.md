# Glossary

**Request**
One call the app makes to an outside API (National Rail or TfL), whether it succeeds, fails or times out. A retry is a separate request.

**Request kind**
What a request was for: a station board, trains home, Tube/DLR arrivals, finding nearby stops, or a station search. National Rail serves the first two; TfL serves the rest.

**Usage**
How many requests this device has made, by request kind, over a period: the last minute, today, the last 7 days or the last 30 days. Usage older than 30 days is forgotten.
